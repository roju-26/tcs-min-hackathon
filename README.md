# ⚡ Code Snippet Generator

A GenAI-powered web application that converts natural-language programming requirements into executable Python code snippets.

## 🚀 About the Project

This project was developed during a **3-hour TCS Technology day Hackathon**.

The goal was to build a tool that allows users to describe a programming requirement in natural language and automatically generate a Python code snippet based on that requirement.

## ✨ Features

- 📝 Enter programming requirements using natural language
- 🤖 Generate Python code using the Gemini API
- 💻 Simple and user-friendly interface
- ⚡ Quick code generation
- 📊 Benchmark suite for evaluating generated code
- 🔐 API key support through environment variables

## 🛠️ Technologies Used

- Python
- Google Gemini API
- Generative AI


## 🔄 How It Works

1. User enters a requirement in natural language.
2. The application sends the requirement to the Gemini API.
3. Gemini generates the corresponding Python code.
4. The generated code is displayed to the user.
